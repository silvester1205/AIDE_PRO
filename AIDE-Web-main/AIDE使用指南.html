AI辅助数据提取工具

系统性综述与Meta分析的文献数据提取助手

🖥️ 本地部署运行

前置要求

  • 安装 Node.js（推荐 LTS 版本）
    下载地址：https://nodejs.org/
  • 下载 AIDE 项目代码到本地

启动步骤

  1. 1. 打开 Node.js Command Prompt
  2. 2. 切换到项目目录：cd /d E:\AIDE\AIDE-Web-main
  3. 3. 安装依赖（首次）：npm install
  4. 4. 启动服务：npm run dev
  5. 5. 浏览器自动打开 http://localhost:5173
💡 提示：后续使用只需执行第 2、4 步。按 Ctrl+C 可停止服务。

什么是 AIDE？

📚 项目背景

  • 用于系统性综述的文献数据提取
  • 基于 LLM（大语言模型）的AI辅助
  • 人机协作验证模式
  • 纯前端应用，无需后端服务器

🎯 核心特点

  • 人工验证每个数据点
  • 支持多种 LLM 模型
  • 提供数据来源溯源
  • 输出标准化编码表单

1配置 API 设置

支持的 API 提供商

  • OpenRouter（推荐）
  • Mistral AI
  • OpenAI 兼容端点
  • 本地模型（LMStudio等）

配置步骤

  1. 1. 进入 Setup 页面
  2. 2. 输入 API 端点 URL
  3. 3. 粘贴 API 密钥
  4. 4. 选择模型（带free标签为免费）
  5. 5. 重要：密钥仅存在浏览器，关闭即清除

2上传编码表单

编码表单定义了需要从文献中提取的数据字段

📋 文件格式

  • CSV (.csv)
  • Excel (.xls, .xlsx)

⚠️ 关键要求

  • 第一行 = LLM提示词
  • 后续行 = 文献数据
  • 提示词越清晰，结果越准确
示例：第一行可以是 "What is the sample size?"、"What is the intervention?" 等

3分析 PDF 文献

步骤 操作 说明
1 上传 PDF 选择要分析的文献文件
2 选择处理模式 Send PDF / Send text only
3 点击 Analyze PDF 发送请求给 LLM
4 查看 Source 展开查看原文出处、页码、章节
5 点击 Record 确认并保存数据点
6 点击 Next PDF 进入下一篇文献

数据核对功能

🔍 Source 溯源

  • 点击 Source 按钮展开详情
  • 显示原始文本片段
  • 显示章节位置（Results/Methods等）
  • 显示具体页码
  • 可一键复制原文

📖 Expand 放大

  • PDF 区域扩展至 70% 宽度
  • 自动放大到 180%
  • 更清晰查看原文
  • 便于核对提取内容
  • 点击 Collapse 恢复原状

重要：每个数据点必须经过人工验证才能 Record！

4导出结果

💾 下载编码表单

  • 前往 Final Coding Form 页面
  • 查看所有已记录的数据
  • 支持导出为 Excel (.xlsx) 或 CSV
  • 包含所有文献的提取结果
⚠️ 数据保存提醒

所有数据存储在浏览器 sessionStorage 中
关闭浏览器标签页后数据会丢失！
请务必在关闭前下载保存编码表单。

⚠️ 重要注意事项

数据安全

  • API 密钥仅存储在浏览器 sessionStorage，关闭即清除
  • PDF 内容仅在本地处理，不会上传到服务器
  • 仅在调用 LLM API 时数据会发送到模型提供商

使用限制

  • 需要稳定的网络连接（调用 LLM API）
  • 免费模型可能有调用限制或准确率差异
  • 复杂表格数据可能需要人工仔细核对

最佳实践

  • 定期下载保存编码表单（建议每篇文献后保存）
  • 使用清晰、具体的提示词（Prompt）
  • 对关键数据务必核对 Source 中的原文
